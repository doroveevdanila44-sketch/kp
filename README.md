# Луна · Коммерческое предложение

Актуальная версия КП со всеми согласованными правками.

## Как загрузить

Загрузите содержимое этой папки в корень репозитория `kp`.

## Как открыть

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для Vercel выберите Framework Preset: Other. Команду сборки оставьте пустой, Output Directory: `.`.
